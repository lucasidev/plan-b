# US-202: Cargar con una fuente no oficial

**Épica**: [Sostener el catálogo](../README.md)
**Del mapa**: BO4-3

## Historia

Como quien carga el catálogo, quiero poder cargar algo cuya fuente no existe o se contradice, porque hay facultades que no publican el plan, o publican dos versiones que no coinciden.

## Listo cuando

- El campo admite marcar de dónde salió el dato, y la ficha lo muestra cuando no es fuente oficial.

## Dónde se resuelve

- [Catálogo](../screens/SC-027-catalog/README.md): un campo se marca "fuente: no oficial" cuando la facultad no publica el plan o se contradice; no bloquea cargar y la ficha pública lo muestra.
- [Correcciones](../screens/SC-028-corrections/README.md): si el campo ya está marcado sin fuente oficial, esta pantalla lo dice al contrastar, en vez de exigir una fuente que no existe.
