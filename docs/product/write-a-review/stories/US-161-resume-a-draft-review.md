# US-161: Retomar una reseña a medias

**Épica**: [Reseñar](../README.md)
**Del mapa**: T3-3

## Historia

Como quien reseña, quiero retomar lo que empecé a escribir, porque cerré la pestaña en el medio y no lo voy a hacer dos veces.

## Listo cuando

- El aporte a medias queda guardado y aparece para retomar la próxima vez.

## Dónde se resuelve

- [Reseñar](../screens/SC-015-write-review/README.md): todo lo ya contestado se guarda solo; si se cierra la pestaña a medias, queda para retomar.
- [Mis aportes](../../undo/screens/SC-018-my-contributions/README.md): lista lo que quedó a medias, con el paso donde se cortó, para retomar o descartar.
- [Error](../../enter/screens/SC-023-error/README.md): si el corte fue por una falla técnica, avisa que lo ya contestado se guardó solo y ofrece el link para retomar.
