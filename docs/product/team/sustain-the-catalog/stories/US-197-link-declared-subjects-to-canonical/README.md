# US-197: Vincular materias declaradas a la canónica

**Épica**: [Sostener el catálogo](../../README.md)
**Del mapa**: BO1-7

## Historia

Como quien carga el catálogo, quiero vincular a la materia canónica las materias que alguien nombró y no están, porque si cada plan tiene su propia materia, las voces del plan viejo no se suman a las del nuevo.

## Listo cuando

- La cola de materias declaradas muestra cuántas personas nombraron cada una, se vinculan o se fusionan contra la materia canónica de la carrera, y queda registrado quién lo hizo.

## Dónde se resuelve

- [Catálogo](../../screens/SC-027-catalog/README.md): la cola de materias declaradas, con cuántas personas nombraron cada una; se vincula a una canónica existente o se fusiona o crea una nueva, con quién lo hizo.
