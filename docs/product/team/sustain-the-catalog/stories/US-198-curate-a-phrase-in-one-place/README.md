# US-198: Editar la frase en un solo lugar

**Épica**: [Sostener el catálogo](../../README.md)
**Del mapa**: BO1-8

## Historia

Como quien cura las frases, quiero editar en un solo lugar el texto, las opciones y la capa de cada frase, porque la capa decide qué bloque de la ficha lo cuenta, y una frase mal definida es un error en todas las fichas que la usan.

## Listo cuando

- El catálogo de frases se edita en un lugar, y cada cambio queda con autor y fecha.
- Editar el texto o las opciones sin cambiar el significado mantiene el mismo código y la misma serie.
- Si el cambio altera el significado, abre un código nuevo y la serie declara el corte: los tramos de antes y después no se comparan entre sí.
- Lo que Método publica es exactamente ese catálogo, entero.

## Dónde se resuelve

- [Frases](../../screens/SC-029-phrases/README.md): el catálogo de frases se edita en un solo lugar; un cambio de significado pide confirmar porque abre un código nuevo.
