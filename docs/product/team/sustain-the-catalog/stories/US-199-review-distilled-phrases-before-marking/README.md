# US-199: Revisar frases destiladas antes de ofrecerlas

**Épica**: [Sostener el catálogo](../../README.md)
**Del mapa**: BO1-9

## Historia

Como quien cura las frases, quiero revisar lo que la destilación propone antes de que se pueda responder, porque una frase que nadie preguntó, ofrecida para responder, se vuelve un hecho que inventamos nosotros.

## Listo cuando

- Las frases destiladas llegan a una cola con los comentarios del campo libre de los que salieron.
- Se aprueban o se descartan con su capa, sus opciones y un código estable asignados; solo se ofrecen para responder después de aprobados.
- La ficha los muestra como destilados: síntesis, no cita.

## Dónde se resuelve

- [Frases](../../screens/SC-029-phrases/README.md): la cola de curaduría de destilados, cada candidato con sus comentarios de origen; aprobar con capa, opciones y código, o descartar sin dejar rastro.
