# US-176: Declarar el estado del canal

**Épica**: [Responder](../../README.md)
**Del mapa**: O7-6

## Historia

Como el docente, quiero que no me presuman el silencio, porque no contestar es una postura, no una admisión.

## Listo cuando

- La ficha declara el estado del canal y nunca el silencio: **"Sin respuesta · avisada el [fecha]"** y, si aplica, "docente sin identidad verificada" (no se le pudo avisar); nunca "no quiso responder" (D06, [registro del 17](../../../../../history/reviews/2026-08-17-catalog-propagation.md)).

## Dónde se resuelve

- [Responder](../../screens/SC-020-respond/README.md): por qué existe esta pantalla incluso cuando nadie la usa.
- [Ficha de cátedra](../../../../student/choose-where-to-study/screens/SC-002-chair/README.md): el bloque "Qué respondió la cátedra" con el estado del canal a la vista, "Sin respuesta · avisada el [fecha]" o "docente sin identidad verificada".
