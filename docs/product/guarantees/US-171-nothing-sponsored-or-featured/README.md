# US-171: Que no me vendan nada

**Épica**: [Que no me molesten](../README.md)
**Del mapa**: O6-4

## Historia

Como quien lee, quiero que no me vendan nada, porque desconfío de cualquier cosa que parezca promocionada.

## Listo cuando

- No hay institución destacada, patrocinada ni ordenada por conveniencia.

## Dónde se resuelve

Es una garantía transversal: no tiene pantalla propia, se verifica en cada ficha de pantalla nueva (la cuarta de las cuatro preguntas del checklist, ver el README de esta épica) y en el [Definition of Done](../../../plan/definition-of-done.md). Donde más se juega:

- [Inicio](../../student/choose-where-to-study/screens/SC-004-home/README.md): nada destacado, patrocinado ni ordenado por conveniencia, tampoco en la muestra de ficha que elige.
- [Dónde estudiarla](../../student/choose-where-to-study/screens/SC-008-where-to-study/README.md): la comparación nunca ordena por valor, destacado o conveniencia.
