# US-157: Reseñar un evento institucional

**Épica**: [Reseñar](../../README.md)
**Del mapa**: O4-13

## Historia

Como quien está cursando, quiero reseñar lo que pasó fuera de una cursada, porque el título que tardó ocho meses no es de ninguna materia.

## Listo cuando

- Se reseña de a un evento, sin materia: frases, comentario opcional y votos igual que una cursada, y sus frases van a la ficha de la institución como lo que se dice de ella como sujeto.

## Dónde se resuelve

- [Reseñar](../../screens/SC-015-write-review/README.md): el paso 1 ofrece la salida "es un trámite, el título, una mesa: un evento, no una materia", con la pregunta de cuándo pasó y sin cátedra.
- [Ficha de institución](../../../../reviewed/reply/screens/SC-005-institution/README.md): sus frases y testimonios entran ahí, como lo que se dice de la institución como sujeto.
