# US-156: Preguntar por mail si me recibí

**Épica**: [Reseñar](../../README.md)
**Del mapa**: O4-12

## Historia

Como quien ya no entra a la app, quiero que me pregunten por mail si me recibí, porque no voy a volver solo para decirlo.

## Listo cuando

- A las cuentas inactivas les llega, una vez al año, un mail con una sola pregunta ("¿te recibiste? ¿cuándo?") respondible desde el mail sin entrar a la app.

## Dónde se resuelve

- [Avisos](../../../../notices/screens/SC-034-mail/README.md): el reenganche anual, una sola pregunta respondible desde el mail sin entrar a la app.

## Notas

depende de avisos por mail
