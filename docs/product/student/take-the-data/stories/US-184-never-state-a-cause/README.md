# US-184: Nunca afirmar una causa

**Épica**: [Llevarse el dato](../../README.md)
**Del mapa**: O8-4

## Historia

Como quien investiga, quiero que no interpreten por mí, porque si me dan la conclusión ya no puedo citarlo como fuente.

## Listo cuando

- Las fichas muestran frases con su moda y su distribución, y la fama por convergencia arriba, que son hechos agregados y no un juicio aparte; en ningún lado se afirma una causa.

## Dónde se resuelve

- [Método](../../screens/SC-021-method/README.md): ninguna ficha afirma una causa; se explicita en la postura.
