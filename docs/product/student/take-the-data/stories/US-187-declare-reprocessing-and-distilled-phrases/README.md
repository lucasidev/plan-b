# US-187: Declarar el reproceso y la destilación

**Épica**: [Llevarse el dato](../../README.md)
**Del mapa**: O8-8

## Historia

Como quien investiga, quiero saber que el catálogo se reprocesa y cuál ítem es destilado, porque una cita que mañana no se reproduce no me sirve, y una síntesis no es una cita textual.

## Listo cuando

- La ficha declara que el catálogo se reprocesa a medida que entran reseñas y con qué fecha se está leyendo, y cada ítem destilado se ve marcado como destilado (síntesis del campo libre, no cita de nadie); el CSV lleva la misma marca.

## Dónde se resuelve

- [Método](../../screens/SC-021-method/README.md): declara que el catálogo se reprocesa y con qué fecha se está leyendo.
- [Ficha de cátedra](../../../choose-where-to-study/screens/SC-002-chair/README.md): donde un ítem destilado se ve marcado como tal.
- [Frases](../../../../team/sustain-the-catalog/screens/SC-029-phrases/README.md): la cola de curaduría donde una candidata aprobada recién ahí se ofrece marcada como destilada.
