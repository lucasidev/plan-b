# US-185: Sin acuerdos con las instituciones

**Épica**: [Llevarse el dato](../../README.md)
**Del mapa**: O8-5

## Historia

Como quien lee, quiero saber que no tienen acuerdos con las instituciones, porque un evaluador que depende del evaluado no me sirve de nada.

## Listo cuando

- La postura está escrita en el método y no hay ninguna institución con trato preferencial.

## Dónde se resuelve

- [Método](../../screens/SC-021-method/README.md): la postura escrita, sin trato preferencial a ninguna institución.
